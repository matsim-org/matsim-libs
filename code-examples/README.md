# MATSim code examples

Small, runnable examples that show how to use and extend MATSim. They were moved here from the archived repository [matsim-code-examples](https://github.com/matsim-org/matsim-code-examples).

Documentation for the examples and for some specific contributions (freight, public transport, profiling, turn restrictions, South Africa scenarios) is in the [matsim-libs wiki](https://github.com/matsim-org/matsim-libs/wiki).
