# MATSim

## Overview

MATSim provides a toolbox to run and implement large-scale agent-based transport simulations. The toolbox consists of several modules which can be combined or used stand-alone. Modules can be replaced by your own implementations to test single aspects of your own work. Currently, MATSim offers a toolbox for demand modeling, agent-based mobility simulation (traffic flow simulation), re-planning, a controller to iteratively run simulations, as well as methods to analyze the output generated by the modules.

A list of all available extensions can be found in the [contribs](https://github.com/matsim-org/matsim-libs/blob/main/contribs/README.md) folder.

For more information, see the project website at https://www.matsim.org/.

## Prerequisites

- **Java 25** (the project is compiled with `maven.compiler.release` set to 25)
- **Maven 3.8 or newer** (enforced by the build)
- **Git**

## Project Structure

The repository is organized into multiple modules:

| Module | Description |
|---|---|
| `matsim/` | Core framework |
| `contribs/` | Optional extensions and contributed modules |
| `examples/` | Example scenarios |
| `code-examples/` | Code examples showing how to use the MATSim API |
| `benchmark/` | Benchmarks |

Extensions in `contribs/` can be used independently or together with the core framework.

## Development

Clone the repository and build it by running the following command from the repository root (not from any sub-directory):

```
mvn package -DskipTests
```

If you want to install the core only, run:

```
mvn install --also-make --projects matsim
```

To run the tests:

```
mvn test
```
